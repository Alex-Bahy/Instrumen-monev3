# 🎓 Instrumen Monitoring dan Evaluasi - SMPN 38 Maluku Tengah

Sistem monitoring dan evaluasi untuk penyelarasan Visi dan Misi Sekolah dengan Pembelajaran Mendalam

## 🚀 Quick Start

### 1. Buka Aplikasi
Buka file `monitoring-evaluasi.html` di browser modern (Chrome, Firefox, Edge)

### 2. Isi Evaluasi
- Pilih menu "Form Evaluasi"
- Isi data evaluator
- Berikan penilaian untuk 8 aspek (skala 1-5)
- Tambahkan catatan
- Submit

### 3. Akses Dashboard (Pimpinan)
- Klik "Login Dashboard"
- Password: `SMPN38MT`
- Lihat statistik dan hasil evaluasi

## 🔧 Setup Google Sheets (Opsional untuk integrasi real-time)

1. Buka Google Sheets
2. Extensions → Apps Script
3. Copy paste kode dari `google-apps-script.js`
4. Run fungsi `setupSheet` dan `setupDashboard`
5. Deploy sebagai Web App
6. Update URL di HTML

## 💡 Tips Penggunaan

1. **Lakukan evaluasi berkala** (minimal bulanan)
2. **Libatkan berbagai evaluator** untuk perspektif yang komprehensif
3. **Fokus pada perbaikan**, bukan sekadar penilaian
4. **Dokumentasikan** temuan dan tindak lanjut
5. **Review hasil** secara berkala dalam rapat

### Dashboard tidak login
✅ Password: `SMPN38MT` (case-sensitive, tanpa spasi)

### Dashboard tidak tampil data
